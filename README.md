# ♾️ DevOps Infinity

A collection of Infrastructure-as-Code (IaC) templates, Docker configurations, and automation scripts for cloud-native DevOps workflows.

## 🚀 What's Inside

| Component | Description |
|-----------|-------------|
| `terraform/` | HCL configurations for AWS/Azure provisioning |
| `docker/` | Dockerfile and compose files for containerization |
| `scripts/` | Python & Shell automation utilities |
| `ansible/` | Playbooks for configuration management |

## 🛠 Tech Stack

- **HCL (Terraform)** – Infrastructure provisioning
- **Python** – Automation scripts and AWS SDK utilities
- **Docker** – Containerization and orchestration
- **Shell** – Bash scripts for CI/CD and server management

## 📦 Quick Start

```bash
git clone https://github.com/supreeth0008/devops-infinity.git
cd devops-infinity
# Review individual module READMEs for setup instructions
```
